# Piste - version Android pour le test du TP

Le fichier à installer est `piste-1.0.0.apk`. Il s'agit d'un APK universel en version release, signé avec la clé propre au projet Piste.

Version 1.0.0 (code 1), Android 7.0 ou supérieur. Architectures ARM 32 bits, ARM 64 bits et x86_64.

## Installer sur un téléphone Android

1. Copier ou télécharger l'APK sur le téléphone Android.
2. Ouvrir le fichier depuis l'application Fichiers ou Téléchargements.
3. Si Android le demande, autoriser l'installation pour l'application qui ouvre ce fichier, puis choisir Installer.
4. Ouvrir l'application Piste.

Aucun compte ni connexion Internet n'est nécessaire pour utiliser le suivi des candidatures. La base est vide à la première installation. Les données de la version Web ne sont pas transférées vers le téléphone.

## Parcours de test

1. Ajouter une candidature : tester le refus d'une entreprise ou d'un poste vide, puis remplir ces deux champs.
2. Choisir un statut, ajouter une note et une date de relance, puis enregistrer.
3. Ouvrir la fiche, modifier le statut et vérifier le résultat.
4. Utiliser la recherche et les filtres, puis consulter Bilan.
5. Fermer complètement Piste et relancer : la candidature doit être conservée.
6. Supprimer une candidature, annuler une première fois, puis confirmer et vérifier le bilan.
7. Refaire les opérations en mode avion pour vérifier le fonctionnement hors ligne.

Cette version a été compilée et sa signature a été vérifiée sur le Mac. Aucun téléphone Android n'était disponible pour un essai physique : le parcours ci-dessus reste à vérifier sur le téléphone du testeur.
